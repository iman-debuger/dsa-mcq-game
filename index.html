DSA Super-Short Formulas & Keywords

📐 Critical Graph & Tree Formulas
  • Tree with N nodes has exactly N - 1 edges.
  • Complete Undirected Graph edges: V(V - 1) / 2.
  • Minimum Spanning Tree (MST) always contains: V - 1 edges.
  • Max nodes at height H: 2^(H + 1) - 1.
  • Max nodes at level L: 2^L.
  • Binary tree (0-based array): Left = 2i + 1, Right = 2i + 2, Parent = floor((i-1)/2).
🔢 Memory Addressing & Queues
  • 1D Array: Base + (i × W)
  • 2D Row-Major: Base + W × (i × Columns + j)
  • Circular Queue Full: (REAR + 1) % SIZE == FRONT
  • Circular Queue Empty: FRONT == -1
⚡ Complexity Hierarchy (Low → High)

O(1) < O(log N) < O(N) < O(N log N) < O(N²) < O(N³) < O(2^N) < O(N!)

Stack: LIFO, Push/Pop, DFS
