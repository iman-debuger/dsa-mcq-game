# DSA Quest: Super-Short MCQ Exam Blitz ⚡

An interactive, high-yield Data Structures and Algorithms (DSA) MCQ arcade game designed for exam preparation (GATE, University exams, technical interviews).

## Features
- **5 Comprehensive Units**:
  - Unit 1: Foundations, Asymptotics, Stacks, Queues & Linked Lists
  - Unit 2: Trees, Binary Search Trees, AVL, Heaps & Priority Queues
  - Unit 3: Graph Algorithms, Traversal (BFS/DFS), MST, Shortest Paths
  - Unit 4: Algorithm Design Techniques (Divide & Conquer, Greedy, Dynamic Programming, Backtracking, Branch & Bound)
  - Unit 5: Advanced Topics, NP-Completeness, String Matching, Hashing
- **Non-Repeating Random Question Engine**: Randomized questions per session.
- **Lifelines & Power-ups**: 50/50, Skip Question, Extra Time.
- **Instant Explanations**: Deep dive into why options are right or wrong after every question.
- **Review Sheet & Analytics**: Comprehensive breakdown of strengths and areas for improvement.

## How to Play / Run
Simply open `index.html` in any modern web browser or deploy with GitHub Pages.
